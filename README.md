# ProductCategoryManager

Система управления категориями и товарами: чтение из JSON, моделирование предметной области, вывод отчёта и полное покрытие тестами.

## Функционал

Проект реализует базовый цикл работы с каталогом товаров:

- **Чтение и парсинг данных**: загрузка структуры категорий и товаров из JSON-файла через модуль `utils`.
- **Моделирование предметной области**:
  - `Product` — модель товара (название, описание, цена, количество).
  - `Category` — модель категории с поддержкой классовых счётчиков `category_count` и `product_count`.
- **Точка входа**: `main.py` собирает приложение, обрабатывает данные и выводит отчёт в консоль.
- **Изоляция зависимостей**: файловые операции вынесены в отдельный слой (`utils`), что позволяет тестировать бизнес-логику без реальных файлов.


## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Запуск

```bash
make run
# или: python -m src.main
```

## Тесты и проверки

```bash
make test    # pytest с покрытием
make lint    # flake8
make type    # mypy
make check   # всё сразу (то же, что и в CI)
```
