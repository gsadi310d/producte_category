# Как вносить вклад

## Ветки

- main — стабильная, защищена проверками CI.
- фичи: feature/<краткое-имя>, фиксы: fix/<краткое-имя>.

## Коммиты

Формат: `<type>: <описание>`, например `feat: добавлен генератор транзакций`.
Типы: feat, fix, refactor, test, docs, chore.

## Перед пушем

```bash
make check
```

CI проверяет то же самое на Python 3.10–3.12.
